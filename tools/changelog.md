## Chaos Gravestone 1.1.0 para Minecraft 26.1

Autor: **Goddark83**.

- Versiones para Fabric, NeoForge y Forge con Java 25.
- Lápidas protegidas, restauración a la ranura original, 18 estilos y brújulas con partículas.
- Brújula de ender con receta vinculada y teletransporte entre dimensiones.
- Guardado de inventario y brújulas pendientes adaptado a los codecs y datos de Minecraft 26.1.
- Renderizado de texto y partículas adaptado al nuevo sistema de estados de renderizado.
- Conserva las comprobaciones de destino seguro, identidad de la tumba y protección en creativo.

Instalar en cliente y servidor. Fabric requiere Fabric API. NeoForge para 26.1 está en beta.

Validación: compilación y autoprueba en una partida aislada para cada cargador. Integraciones con inventarios de accesorios pendientes.
